# 🎓 Placement Analytics Cell

A web-based Placement Analytics system for managing campus recruitment data, designed to serve both **students** and **placement management**.

---

## 🚀 Features

### 👨‍🎓 Student Portal
- Student login & authentication
- View list of visiting companies
- View details like:
  - Company name
  - Offered package
  - Job role
- Apply to companies 

### 🧑‍💼 Management Portal
- Admin/Management login
- Add/edit/delete company records
- View list of students who applied to each company
- View analytics of student applications 

---

## 🏗️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript / React.js
- **Backend**:  Node.js 
- **Database**:  MongoDB
- **Authentication**: Session

---

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Surbhi-debug/TRAINING-PLACEMENT-CELL.git
   cd placement-analytics

2 . Set up Backend and Frontend

npm init -y

npm install express

npm install ejs

npm install mongoose

npm install body-parser

npm install bcrypt

npm install express-session

npm install connect-mongo

npm install dotenv

npm install --save-dev nodemon


3 . Run the project with:

npm start
